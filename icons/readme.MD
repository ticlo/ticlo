## Icons

`functions/` contains the SVG backgrounds used by function icons and drag feedback.
`files/` contains custom file icons, matching Ant Design's file outline and using
`currentColor`. Run `pnpm build-icons` after editing SVGs; see
[icon assets](../docs/function-icons.md#svg-backgrounds).

Font Awesome assets are from [Font Awesome](https://github.com/FortAwesome/Font-Awesome/tree/090e6148d3f63a45b40e7cd8679bd4d64e58d75d/svgs)
and are licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
The area chart, line chart, stock, and custom file outlines are from
[Ant Design Icons](https://github.com/ant-design/ant-design-icons) and are licensed under MIT.
